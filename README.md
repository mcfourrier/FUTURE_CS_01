# FUTURE_CS_01
Vulnerability Assessment Report for a Live Website

## 👨‍💻 Author

Kaloufei Essowè

## 🛠️ Tools Used

* Nmap
* OWASP ZAP (Passive Scan)
* Browser DevTools
* Canva (Report Design)

## 🎯 Objective

To identify, analyze, and report web vulnerabilities in a target application.

## 🔍 Key Activities

* Performed vulnerability scanning using OWASP ZAP
* Identified security issues
* Classified risks (Low / Medium / High)
* Provided remediation steps

## ⚠️ Vulnerabilities Found

* Missing Security Headers
* Information Disclosure
* Cookie Security Issues

## 🔥 Possible Attacks

* Man-in-the-Middle (MITM)
* Session Hijacking
* Cross-Site Scripting (XSS)

## 🛡️ Recommendations

* Implement security headers
* Secure cookies (HttpOnly, Secure)
* Use HTTPS properly

## 📂 Deliverables

* Full report (PDF)
* Scan results
* Screenshots
